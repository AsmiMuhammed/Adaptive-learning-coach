
# AdaptIQ — Adaptive Learning Coach

An AI-powered adaptive learning system for Hackathon Problem 8.

## Objective
Personalize learning based on student performance and progress.

## Core Features
- Reinforce: Provide revision and practice exercises.
- Advance: Unlock harder lessons when the learner is ready.
- Mentor: Recommend human support when necessary.
- Explain decisions and update learner progress records.

## Technology
- Python
- Flask
- React
- CSV-based learner records
